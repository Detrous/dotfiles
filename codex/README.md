# Codex configuration

`AGENTS.md` contains global Codex instructions. `../setup.sh` links it to
`~/.codex/AGENTS.md`; edit the file here, not a separate copy in your home directory.
The setup script leaves Codex settings, authentication, plugins, and history in place.

Adapted from `../claude/CLAUDE.md`: preserves atomic changes, deliberate staging,
verification, and Conventional Commits. Clarification is limited to consequential
uncertainty; routine choices follow repository conventions. Claude model routing
and the `@RTK.md` import are omitted. No automatic commits or pushes are requested.

Start a new Codex task after changing instructions so it loads the updated guidance.
